③ Update Memory：使用未来折扣 Advantage
$\widetilde A_{i+k}^{\mathcal M,(n)}=\displaystyle\sum_{j=k}^{K}\gamma^{j-k}A_{i+j}^{(n)}$
早期 memory 更新会影响后续状态，因此接收当前位置到窗口终点的折扣优势。
④ Generate Suggestion：只使用当前 Advantage
$\widetilde A_{i+k}^{\mathcal S,(n)}=A_{i+k}^{(n)}$
Suggestion 只决定当前位置的输出与奖励，直接使用同位置组间优势更新。
⑤ 每个动作都使用 GMPO 目标更新
将上方对应的 $\widetilde A^{\mathcal M}$ 或 $\widetilde A^{\mathcal S}$ 作为 $\hat A_i$
$$\mathcal{J}_{\text{GMPO}}(\pi_\theta)=\mathbb{E}\left[\frac{1}{G}\sum_{i=1}^{G}\operatorname{sgn}(\hat{A}_i)\left\{\prod_{t=1}^{|o_i|}\left|\min\left(\rho_{i,t}(\theta)\hat{A}_i,\ \operatorname{clip}(\rho_{i,t}(\theta),\epsilon_{\mathrm{low}},\epsilon_{\mathrm{high}})\hat{A}_i\right)\right|\right\}^{\frac{1}{|o_i|}}\right]$$
这里 $G=N$（同一起点的并行短轨迹数）；$o_i$ 是一次 Memory Update 或 Suggestion 的输出 token 序列。
